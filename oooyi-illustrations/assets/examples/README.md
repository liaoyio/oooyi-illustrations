# 当前小星示例

以下两张按当前 `oooyi-illustrations` 的角色与白底手绘规则生成，用于低频校准。需要参考时，从下表选择与当前问题相关的图片；不要默认加载整套图片，也不要照抄物件、构图或标注。

| 示例 | 图片 | 校准重点 |
| --- | --- | --- |
| 信息过滤 | [filtering.png](filtering.png) | 小星亲手筛选信息，以一个动作表达“留下可行动线索” |
| 先验证再投入 | [validation.png](validation.png) | 用低成本小样试验表达验证判断，小星是核心动作执行者 |

两图采用 16:9 纯白画布、细黑手绘线、小小的远景全身角色和少量中文批注。角色设计以 `../../references/character/` 的两张基准图为准，基准图只取设计元素；不要继承 3D 或写实画风。

本目录其余四张为早期小星样例，保留作对照。旧版小黑图另存于 `../archive-xiaohei/`，均不属于上表的当前校准集。
