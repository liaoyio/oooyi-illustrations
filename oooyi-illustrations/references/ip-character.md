# IP 角色圣经：小星 (Xing)

## 一句话

小星是 oooyi-illustrations 的固定视觉 IP：一个浅金短发的酷男孩，脸上没什么表情，却在认真做着有点荒诞的事。

酷是他的样子，荒诞是他的处境——反差感是记忆点来源。

## 外形锁定项（★ = 绝不能走样）

- 脸：清秀少年脸，大眼睛，蓝灰色眼珠，眼神略带疏离；浓重腮红＋雀斑（鼻梁和脸颊）。
- 发（★）：浅金色短碎发，蓬松凌乱；前发有一缕蓝灰色挑染。
- 配饰（★）：左侧银色镭射星星发夹；左耳银色星星耳坠（双星吊坠）。
- 上衣：白色细条纹宽松衬衫。
- 颈（★）：绿色针织三角巾，随意系着。
- 下装：浅蓝色宽松阔腿牛仔裤，黑色皮带。
- 腰间：棕色皮质钥匙扣挂饰（非锁定，可省略）。
- 鞋：白色板鞋。
- 气质：酷、淡定、疏离，面无表情；荒诞处境里保持冷静。

## 表情库

- 面无表情（默认）：眼神平静，嘴唇轻抿。
- 专注：微微皱眉，盯着手里的东西。
- 疑惑：眉头轻挑，眼神斜向一边。
- 小得意：嘴角极轻微上扬（克制，不要大笑）。

## 服装变体规则

- 默认穿搭＝上面锁定的整套，日常图一律用它。
- 换主题服装时：脸、短发＋挑染、星星发夹、星星耳坠这四项不许动，只换衣服。

## 手绘版表现规范（正文配图用）

正文配图走黑白手绘线稿风时，小星按以下方式简化表现，设计元素一个不丢：

- 整体：黑色手绘线稿，线条轻微抖动；小小的一只：全身占画面高度 ≤1/3（目标 ~1/4）；先画大场景再把他放进去；远景全身，禁近景；画成男孩子，不要画成小女孩。
- 发：短碎发的潦草线条，前发画一缕挑染（可罩淡蓝灰）。
- 配饰：左侧星星发夹画成小涂鸦；左耳画星星耳坠。
- 脸：少年脸简笔画，大眼睛眼神疏离；脸颊画腮红线＋雀斑点；不要画成圆脸小女孩。
- 衣服：条纹衬衫＋绿领巾＋阔腿牛仔裤＋板鞋，全部线稿勾形。
- 上色（克制）：绿领巾可罩淡绿，挑染可点淡蓝灰；其余一律黑白。
- 禁止：画成 3D 人偶、照片级写实、精致渲染；禁止把他画大（近景大头贴）；禁止画成女孩子；禁止表情包式大笑。

## 禁止

- 不许改发色、瞳色、发型（不许加长发、不许去掉挑染）。
- 不许动星星发夹和星星耳坠的款式和位置。
- 不许改掉脸上的腮红和雀斑。
- 不许把他画成女孩子。
- 不许让他只当背景板：他必须是核心动作的执行者。
- 不许油腻、不许性暗示。
